LOST DASHBOARD

Como usar:
1. Extraia a pasta.
2. Abra o arquivo index.html no navegador.
3. Cadastre receitas, despesas, estoque e anotações.

Observações:
- Os dados ficam salvos no navegador usando localStorage.
- Para colocar online grátis, suba a pasta no Cloudflare Pages, Netlify ou GitHub Pages.
- O visual é inspirado no painel que você mandou, mas com identidade própria para evitar cópia direta.
